MEDIA FOLDER - put all your files here
======================================

Every video, image and sound your story uses goes in this folder.
The story file only needs the file name, never a path.

Rules for file names
--------------------
- lowercase letters, numbers, hyphens and underscores only
- no capitals, no spaces, no accents, no brackets
- good:  movie1_cadburyegg.mp4   stairs-clip.mp4   btn-open.png
- bad:   Movie One.mp4           stairs clip.MP4   boton (1).png

File types
----------
- video:  .mp4  (H.264 + AAC, 720p or 1080p, 25 fps)
- image:  .png  or  .jpg   (PNG if you need transparency)
- audio:  .mp3

Hover images
------------
A button image like btn-open.png automatically uses
btn-open-hover.png when the mouse is over it, if that file exists.

The error checker warns about every file that does not follow
these rules, and about every file named in the story that is
missing from this folder.
